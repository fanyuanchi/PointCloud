## 📦 Point Cloud Data Preprocessing

This module provides scripts for preprocessing raw point-cloud data.  
It converts `.las` / `.laz` files into cleaned `.csv` format,  
which is required for running the PC-PS experiments.

---

## 🚀 How to Use
### 1. Environment Setup

Make sure the `laspy` package is installed:

```bash
pip install laspy

### 2. Prepare Raw Data

Download the raw point-cloud datasets (e.g., `.las` / `.laz` files)  
from the link provided in the root README.

---

### 3. Configure Paths

Update the input and output paths in the main script  
to match your local environment.

---

### 4. Run Preprocessing

Execute the preprocessing script.
